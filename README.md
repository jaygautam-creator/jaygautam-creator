### What I'm building now

**Aletheia** — an evidence-grounded, multi-agent verification framework that checks whether an LLM's claim is actually supported by the underlying literature, instead of trusting its confident tone. Ships with a real evaluation harness. → **[live demo](https://aletheia-kappa-one.vercel.app)** · **[repo](https://github.com/jaygautam-creator/Aletheia)**

**RampBrain** — engineering onboarding rebuilt around an *executable skills* layer instead of another doc-search bot. New engineers (and agents) learn a codebase by running real tasks against it, not by reading about it. → **[rampbrain.com](https://rampbrain.com)**

**YuvaDev** — an agentic coding platform: a loop engine, an MCP client, and a CLI that let a model do the work while diff review stays firmly human. Built in an "editorial × terminal" key.

**Automated trading-research loop** — a hands-off paper-trading system for Indian index options. Scheduled watchers, a news feed, and a daily AI analyst score every setup *net of costs* before any capital is committed — an exercise in disciplined automation, not a tip sheet.

*RampBrain, YuvaDev, and the trading loop are private for now — happy to give a walkthrough.*
