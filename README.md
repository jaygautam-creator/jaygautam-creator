### ◆ &nbsp;Selected work

| | Project | What it is |
|:-:|:--|:--|
| `05` | **[Support Triage Agent](https://github.com/jaygautam-creator/hiver-support-agent)** | First-response agent for @AppleSupport built from 2.8M tweets — intent, grounded reply, and an escalation decision citing policy. The evaluation is the point: a blind control, a second annotator, and ablations that each cost the headline something. |
| `06` | **[DealFlow360](https://github.com/jaygautam-creator/dealflow360)** | Self-governing B2B sales ops: discount governance, approval routing that fails closed, multi-warehouse fulfilment, hybrid billing. Odoo Hackathon 2026 Grand Finale, 24-hour solo build. |
| `07` | **[Dyla](https://github.com/jaygautam-creator/dyla-stump-the-model)** | Visual search for jewellery — CLIP + FAISS over 7,000+ catalogue photos, tested on hand-shot hard phone photos. [Live →](https://frontend-neon-nine-bl3oyccpzz.vercel.app) |
| `08` | **[CuraLens](https://github.com/jaygautam-creator/CuraLens)** | AI-assisted oral-cancer screening — image analysis and risk scoring to support clinicians at the point of care. |
| `09` | **[Blackout Protocol](https://github.com/jaygautam-creator/Blackout-Protocol)** | Offline SOS mesh network for disasters — messages hop phone-to-phone until one device reaches the internet. |
